# Arogyama — clinic panel (doctor app)

Risk-sorted patient list, BP chart, adherence, vaccines, EPDS, counselling, PPIUCD, notes, access log, hide-names, auto-lock. Shows only what each patient shared. Demo data. English, Tamil, Hindi.

`npm install && npm run dev` · `npm run build` → `dist/index.html`.

Deploys on Vercel with no settings (see `vercel.json`).
